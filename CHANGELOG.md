# История изменений

## 1.3.0 — 17 ноября 2026

### Интерфейс
- Исправлены переносы и вертикальное выравнивание вкладок «Анализ» и «Управление линиями».
- Разделены иконки и текст на кнопках «Сохранить» и «Загрузить».
- «Сортировать по» заменено на «Сортировать»; подпись немного сдвинута влево.
- Сокращены подписи, которые накладывались на числа или соседние строки:
  - «Стоимость» → «Цена»;
  - «Чистые активы» → «Активы»;
  - «Продано за прошлый месяц» → «За месяц»;
  - «Общая прибыль» → «Прибыль»;
  - «Ежемесячные расходы» → «Расходы»;
  - «Лицензионные отчисления» → «Роялти»;
  - «Модернизировать линии» → «Модернизация»;
  - «Автоматизировать» → «Автоматизация»;
  - «Выход годных (…)» → «Выход (…)».
- Фильтры сегментов рынка сокращены до «Премиум», «Средний», «Бюджет», «Пром.». Устранено переопределение коротких вариантов длинными из второго словаря.

### Перевод
- Добавлены статусы создания процессора: Testing → «Тестирование», Designing → «Проектирование».
- Словарь содержит 736 точных записей и 120 шаблонов динамического текста.

### Установщик
- Добавлена резервная проверка обновлений через официальную страницу последнего релиза GitHub, если API недоступен или исчерпан лимит запросов.
- Общий таймаут проверки — 4 секунды. Отсутствие сети не мешает установке.
- Проверены сравнение версий, сетевые ошибки, отмена запроса, ограничение API и переход к резервному способу. Окно обновления подтверждено пользователем в проверочной копии установщика.

Пользователь повторно проверил показанные проблемные экраны в тестовой игре и подтвердил исправления. Полное прохождение, все поздние события и все разрешения экрана отдельно не проверялись.

## 1.2.0
- Добавлена проверка обновлений при запуске графического установщика с предложением открыть новый релиз.
- Сокращены главные подписи: «Новое», «Производство», «Продажи», «Выпуски:».

## 1.1.0
- Сокращены подписи производства и других узких элементов интерфейса.
- Добавлены переводы динамических сроков, статуса разработки, плотности транзисторов и вариантов «Калькулятор» / «Консоль».
- Добавлены точечные правила подбора размеров текста для отдельных окон.

## 1.0.0
- Первый опубликованный русский перевод Processor Tycoon 0.2.3 для Windows x64 Mono.
- Однофайловый установщик с установкой, проверкой и удалением русификатора.
