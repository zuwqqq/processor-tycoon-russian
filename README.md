# Processor Tycoon — русификатор

Неофициальный русский перевод предоставленной Windows x64 Mono-версии Processor Tycoon 0.2.3.

**Скачивание:** откройте [последний релиз](../../releases/latest) и скачайте `ProcessorTycoon-Russian-Setup.exe`. Все необходимые компоненты включены, интернет при установке не нужен.

## Установка

1. Закройте игру и запустите EXE установщика.
2. Выберите папку с `Processor Tycoon.exe`.
3. Нажмите «Установить» и запустите игру обычным способом.

Удаление: запустите тот же EXE и нажмите «Удалить русификатор».

## Состав перевода

- 726 уникальных словарных записей и 117 шаблонов динамических сообщений.
- Меню, настройки, рабочий стол, исследования, производство, контракты, письма и подсказки.
- Одинаковый размер пяти пунктов главного меню.
- Отображаемый текст переводится через TextMeshPro; исходные значения для настроек и игровой логики сохраняются.
- BepInEx 5.4.23.3 и Newtonsoft.Json 13.0.3 включены в установщик.

## Проверка и ограничения

Проверены запуск, кириллица, меню, настройки, создание новой игры, рабочий стол и исследования. Пройдено 1633 автоматические проверки перевода, проверены установка/повторная установка/удаление, контрольные суммы и сохранность сторонних файлов. Полное прохождение, все поздние события, все разрешения экрана и все сочетания других модов не проверены. Единичные пропуски и тесные надписи возможны.

Установщик отказывается заменять отличающийся общий загрузчик/ядро других модов. При удалении сохраняет общий BepInEx, если обнаружены другие плагины или патчеры. Сохранения вне папки установки не затрагиваются. Не удаляйте папку `.processor-tycoon-russian`: в ней состояние установки и резервные копии.

Для других версий игры совместимость не подтверждена. Имена, марки, технические сокращения и некоторые единицы намеренно не переводятся.

## Об ошибках

Создайте Issue: укажите версию игры, экран, исходную надпись и приложите скриншот. Если есть ошибка загрузки, приложите `BepInEx/LogOutput.log`, удалив личные данные. Локальный журнал неизвестных строк находится в `BepInEx/plugins/ProcessorTycoon.Russian/untranslated.log` и никуда автоматически не отправляется.

## Исходники

`source/plugin` — плагин; `source/translations` — словари; `source/installer` — установщик; `source/tests` — проверки. Файлы самой игры не распространяются. Для сборки плагина нужны DLL из вашей копии игры и BepInEx; локальные пути в проекте требуется настроить.

`docs` — статическая страница GitHub Pages. В настройках Pages выбрана публикация из папки `/docs` ветки `main`.

## Правовой статус

Проект неофициальный, не связан с разработчиком игры. Название и материалы игры принадлежат соответствующим правообладателям. BepInEx и Newtonsoft.Json распространяются на условиях MIT; уведомления включены в релиз.
